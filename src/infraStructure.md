# 🧱 WebForge: Component Infrastructure Library

> **"We're not building websites. We're building the LEGOs that build websites."** 🏗️

A vanilla JS + HTML + CSS component library designed to scale to **1000+ websites**. Every block is a reusable, resizable, adjustable React-like function — without the React.

---

## 🎯 Core Philosophy

| Principle | Description |
| ----------- | ------------- |
| 🧩 **LEGO Blocks** | Every component is self-contained & composable |
| 📏 **Scale First** | Built for 1000+ sites, not one |
| 👁️ **Readability Max** | Human-readable / Understandability > clever code |
| ⚡ **Right-Sized Power** | Each function has exactly the power it needs |
| 🔧 **Resizable & Adjustable** | Everything is tunable at runtime |
| ⚛️ **React-like, Not React** | Function-based returns, no framework tax |
